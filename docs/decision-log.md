# decision-log.md (ADR: 意思決定記録)

プロジェクトにおける技術選定、ツールの試用・導入判定（Spike）、設計例外の決定経緯を簡潔に記録する。
**AIはツール試用前に本一覧を確認し、過去に検証済みのツールの再検証を行わないこと。**

---

## 記録フォーマット

```markdown
### [YYYY-MM-DD] タイトル（例: ツール試用: ライブラリ名 / 設計例外）
- **ステータス**: 採用 / 見送り / 例外承認
- **用途・背景**: なぜ検討したか
- **検証結果・判断理由**:
  - メリット:
  - リスク・デメリット:
- **結論**: 今後の方針（採用時は利用コマンドやスクリプトパスを記載）
```
