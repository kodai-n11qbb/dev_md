# Graphify スキル（コードベース・ドキュメント構造探索）

> **目的**: ファイルの丸読みや手動の巨大目次（index.md）を廃止し、ナレッジグラフから必要な依存パスのみをピンポイントで取得する。

---

## 1. 探索の原則
- **ファイルの全読み（丸読み）を禁止する。**
- コードや仕様の調査を行う際は、まず `graphify-out/` 配下の構造化データ（`GRAPH_REPORT.md` または `graph.json`）を参照し、関連するノードとエッジ（依存関係）のみをピンポイントで読み込む。

---

## 2. 実行コマンド（必要時のみ）
リポジトリの構造に大きな変更があった場合、または初回解析時は以下を実行する：

```bash
# グラフの生成・更新（ローカルAST解析・0トークン消費）
graphify .
```

生成される出力物：
- `graphify-out/GRAPH_REPORT.md`: アーキテクチャサマリー、重要ノード（God Nodes）、コミュニティ構造
- `graphify-out/graph.json`: AIエージェントがピンポイントでクエリするための構造化グラフ
- `graphify-out/graph.html`: 視覚的なグラフ可視化

---

## 3. クエリ手順
1. `graphify-out/GRAPH_REPORT.md` で対象機能がどのコミュニティ/クラスタに属するか特定する。
2. 対象ファイル・関数の依存元・依存先ノードのみをピンポイントで開く。
